                NEXUS ARCADE · EMULATORJS
                
🕹️ Game Boy / Game Boy Advance

                
Play a game from a ROM file already on your device. Powered by EmulatorJS using its official stable engine. Supports GBA, GB and GBC files.

            

            

                
                
            

        


        
        
        

            
            Your ROM is read locally in your browser; NEXUS does not upload it.
        


        

            

                
🎮

                Ready when you are.

                Select a compatible game file, then press Load Game.
            

        


        

            
            Press and hold to speed up gameplay; release to return to normal speed. Keyboard shortcut: Shift.
        


        
Engine not loaded. It downloads from the official EmulatorJS CDN only when you press “Load Game”.


        
⌨️ Game Controls

        

            Move — Arrow keys
            A button — Z
            B button — X
            L / R — Q / E
            Start — Enter
            Select — V
            Fast-forward — Hold Shift
            Gamepad — Connect before starting; remap in Controller Settings
        

        
Save / Load: Use the emulator toolbar's Save State and Load State buttons. Quick Save / Quick Load are also enabled. In-game battery saves are stored in this browser. Do not clear browser site data if you want to keep them. You can also export/import save files from the emulator toolbar. No ROMs or BIOS files are included.

🌌 About NEXUS

    
Your Digital Universe.


    

        
One Dashboard. Many Possibilities.

        

            NEXUS is a personal digital command centre designed to bring
            useful tools, productivity features, coding experiments and
            gaming information into one place.
        

        

            It is built using HTML, CSS and JavaScript, without requiring
            a heavy framework.
        

        
Project Information

        
Project: NEXUS

        
Version: 2.0

        
Technology: HTML + CSS + JavaScript

        
Design: Black and Neon Purple

        
Storage: Browser Local Storage

        
Built to grow. Built to explore.

            Notes, tasks, games and settings are stored in this browser
            on this device. They are not automatically synchronized
            with other devices or backed up online.
        

        
Export a backup before clearing browser data or moving to another computer.
